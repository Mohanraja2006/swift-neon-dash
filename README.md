# Neon Runner: City Dash

Create a simple but unique browser game called “NEON RUNNER”.

Game Idea

The player controls a small futuristic character running through a neon city. The player must avoid obstacles, collect coins, and survive as long as possible.

Features

- Start Game button

- Keyboard + mobile touch controls

- Character automatically runs

- Jump and slide controls

- Random obstacles

- Collect coins

- Score increases with distance

- Speed slowly increases

- High score saved using localStorage

- Game Over screen

- Restart button

- Pause button

- Sound ON/OFF button

Design

Make it look premium, modern and different:

- Dark futuristic background

- Neon glowing effects

- Smooth animations

- Moving city background

- Particle effects

- Glowing buttons

- Glassmorphism UI

- Smooth screen transitions

Extra

Add:

- Coin collection animation

- Score animation

- Speed indicator

- Combo system

- 5 achievements

- Different character skins that unlock with coins

- Difficulty increases over time

Mobile

Make it fully responsive and playable on Android phones.

Technology

Use only:

- HTML

- CSS

- JavaScript

- Bootstrap if required

No backend required.

Most importantly, make it a fully playable game, not just a UI design. Every button and game mechanic must actually work.
